# 学生练习动作问题说明实施记录

日期：2026-09-18。按用户选择接入旧版 `apps/app_ui.py` 的“学生练习”。按用户明确纠正，评判仅使用现有 MediaPipe 关键点及几何/时序规则，不使用 Qwen、视觉语言大模型、本机 HTTP 服务或 GPU。正式评分、考试台账和旧默认链路不变。

## 使用

启动旧版桌面，进入“学生练习…”，填写学号、选填姓名，选择动作和左式/右式。选择双摄后点击“开始”，进入正面预览的黄色站位框站稳0.8秒，系统播报“开始”并自动录制；离开该区域连续2秒后播报“结束”并停止录制。短暂离开后回到区域内会重置2秒计时，也可手动点击“结束”（尚未到位时取消等待）。等待转码落盘后点击“动作评判”；再次练习需重新点击“开始”。学生、动作和左右式在开录时绑定，等待到位期间锁定填写项。

2026-09-19新增：复用考试模式的MediaPipe Lite站位检测、`PresenceGate`与异步语音播报，按正面画面髋部中点判定是否进入区域。站位框沿用考试模式保存的ROI，没有配置时使用默认区域；需要更改位置时，先在教师界面的“考试模式…”中设置并保存ROI，再进入学生练习。练习的离场阈值固定为2秒，不叠加考试的最短录制3秒限制。语音不可用时仍显示文字提示。

支持实战式、前后手直拳组合、前后手摆拳组合、前/后低鞭腿；也可选单独前后手拳法。通过“导入旧视频”选择仍保留的正面/侧面原视频，补充历史分析。单视角可检查其支持的项目，缺视角明确标为无法判断。

“个人历史”按学号显示结果，支持UTF-8文字导出、重新分析以及教师确认/撤销。撤销项留存但不进入报告的当前问题清单；复核保存教师姓名、前后状态、原因和时间。重分析保留旧版结果与复核，新结果重新等待复核。本机教师署名不是账号鉴权。

## 实际推理链路

`apps/app_ui.py` → `apps/feedback_panel.py` → `core/feedback_history.py` → `core/action_feedback.py` → `core/feedback_geometry.py` → 现有 `MediaPipePipeline`。

- 单个 MediaPipe Lite、显式 CPU delegate、VIDEO 跟踪模式、关闭手部检测。正侧视频串行处理，每路结束释放模型，不常驻大模型服务。
- 最长边缩至640像素，按不高于12帧/秒采样；顺序解码，只留关键点，不缓存完整视频帧。
- 复用 `derive_valid_mask`、原规则引擎的角度函数、屈膝和脚尖方向检查。不改它们的正式评分行为。
- 丢失帧全部标为无效，不能沿用上一帧姿态。x/z按画面宽高比校正到同一尺度后算几何量，避免非正方形视频角度失真。
- 首尾稳定窗口作为实战式；以指定肢体相对躯干的离开和回收检测动态阶段，最大位移附近作为动作结束瞬间。前后组合必须分别有一个清晰事件且顺序明确，不能机械平分录像。当前不自动识别拳法类别，动作类型由用户选择；重复、重叠或不可分段动作提示重新录制。
- 按有效帧占比、违规帧占比形成规则问题；缺有效关键点/视角/阶段、正侧判断冲突时不判为合格。翻胯/甩手等“未做”检查要求在整个被检阶段均未观察到该动作，不能因起始帧尚未完成就报错。
- `FeedbackConfig` 保留采样、阶段检测和几何容差标定入口；结果保存所用配置。工程阈值尚未经指定教师样本验收，因此 `calibrationStatus=unvalidated`、`scoreAuthorized=false`，不输出总分或扣分。
- 取消在逐帧推理前及保存前检查，不再等待HTTP请求。缺少Lite模型时明确提示通过既有“设置→模型管理”安装，不在分析过程中静默下载。

## 规则依据与边界

依据 `docs/扣分点说明功能需求汇总.md` 和 `docs/武术散打得分点.docx`。本次读取的Word表1共18行：开始实战式3～9行、直拳10～11行、结束实战式12～18行；其中没有摆拳或低鞭腿，后两类按需求汇总3.3/3.4节纳入。Word第11行的前手向后拉手补足汇总遗漏。原文2分/15分不进入新模块计算。

| 检查项 | 实现与限制 |
| --- | --- |
| 前手肘角90°～135° | 按左/右式选择实际前手，计算二维肩肘腕夹角；不以任一手合格替代前手。仍有投影误差。 |
| 后手护位、掉手、抬肘、回收 | 手腕/口部/肩肘/躯干的相对距离与高度规则。 |
| 向后拉手 | 侧面视角相对初始护位的位移；前向不明确时无法判断。 |
| 屈膝、脚尖、躯干朝向、肩部齐平 | 关键点角度、方向和相对高度/宽度规则。 |
| 低鞭腿勾脚尖、翻胯、同侧甩手 | 侧面膝踝脚尖夹角、髋轴相对初始姿态转动、手腕下摆位移；髋深度来自MediaPipe估计，非真实三维测量。 |
| ±3 cm、±10 cm | 保留标准和出处；没有长度标定不能换算成真实厘米，标记待测量确认。 |
| 立拳、含胸收腹 | 轻量Pose关键点不可靠覆盖这些细节，标记需教师查看。 |
| 摆拳抬肘与阶段错字、出拳侧护手规则 | 保留条目及原文疑点，未明确阶段边界前不自动报错。 |

按开始、前手、后手、结束及身体部位列出全部问题；同一检查编号不重复计次数。未发现问题不等于所有项目合格，同时显示未完成判断的项目。规则来源与数值依据不等于识别准确率已验收。

## 保存与两周保留

`outputs/practice_feedback/<随机编号>/` 保存视频副本、结果和复核记录，与考试台账分开。学号不参与文件路径。原子替换保存记录，分析未完成不出现在历史列表。

保留期从首次导入/分析起计14天，复核/重分析不续期。访问历史时清理到期的受管副本及结果；程序关闭期间不运行删除服务。外部导入文件、原录制目录中的原文件及用户导出的报告不由本模块删除，原录像的统一到期管理仍需明确所有权。
